# CHRONOS — Luxury Watch Landing Page

A modern, highly-performant, and visually stunning luxury watch landing page built with Next.js, Tailwind CSS, and Framer Motion. This project serves as an editorial showcase for high-end timepieces, featuring a buttery-smooth scroll-driven canvas animation.

## ✨ Features

- **Scroll-Driven Sequence Animation**: A fully optimized HTML5 `<canvas>` implementation that renders 240 high-resolution frames tied directly to the user's scroll position, creating a 3D rotating watch effect without browser lag.
- **Cinematic Typography & Layout**: High-end fashion editorial design aesthetics using elegant serif typography, dark themes, and subtle glassmorphism.
- **Micro-Interactions**: Smooth fade-ins, stagger effects, and parallax elements powered by Framer Motion.
- **Fully Responsive**: Perfectly scaled for mobile, tablet, and ultra-wide desktop monitors.
- **Modern Tech Stack**: Built on the bleeding edge using Next.js 16 (App Router), TypeScript, and Tailwind CSS.

## 🚀 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📂 Project Structure

- `/src/components/layout/` - Global layout elements like the Header and Navigation.
- `/src/components/sections/` - The core building blocks of the landing page (HeroSection, AboutSection, ServicesSection).
- `/src/components/ui/` - Reusable micro-components (Buttons, Section Labels).
- `/src/lib/` - Shared utilities and Framer Motion animation variants.
- `/public/images/` - Static assets and the 240-frame sequence for the canvas animation.

## 🎨 Design Philosophy

This project strictly adheres to luxury design principles:
- **No Clutter**: Generous use of negative space.
- **Color Palette**: Deep blacks, warm off-whites (`#F5F3EF`), and subtle emerald green accents.
- **Typography**: A striking balance between `Playfair Display` (Serif) for headings and `Inter` (Sans-Serif) for crisp readability.
